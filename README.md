# Portal Guru — GitHub Pages PWA

PWA shell untuk Portal Guru yang sudah berjalan di Google Apps Script.

Apps Script URL: `https://script.google.com/macros/s/AKfycbx-hiYq6ms1E5_66HQVvFmHd7cYyTukONcWw9llO9F9flW3Q52AeH0snmZR1_s-jdMO/exec?app=guru`

Upload isi folder ini ke **root** repository GitHub.
Kemudian Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

PWA menggunakan `display: standalone`, sehingga setelah di-install akan terbuka seperti aplikasi tanpa address bar. True fullscreen tidak dapat dipaksa oleh website biasa tanpa tindakan pengguna.
